Function Ordina

Autore:            

Data:                 28/06/2000

Scopo:

Ricerca il foro della corona esterna che minimizza la funzione obiettivo.

Listato:

Function Ordina(NewDist() As Single, NewInd() As Integer, indice As Integer, _

         Mode As Integer) As Integer

         Dim ii As Integer, Distl As Single

         Dim Ind As Integer

         If Mode = 1 Then

            For ii = 1 To indice

               If NewDist(ii) < 0 Then NewDist(ii) = -NewDist(ii)

            Next

         End If

         Distl = 1E+20

         For ii = 1 To indice

            If NewDist(ii) > 0 And NewDist(ii) < Distl Then

               Distl = NewDist(ii)

               Ind = ii

            End If

         Next

         NewDist(Ind) = -NewDist(Ind)

         Ordina = Ind

End Function
