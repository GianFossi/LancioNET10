Function iSector

Autore:            

Data:                 28/05/2000

Scopo:

Restituisce il numero del quadrante goniometrico  nel quale è situato il punto p.

Chiamata da DistInMem

Listato:

Private Function iSector(p As Vec2) As Integer

    Select Case p.x

        Case Is < 0

           Select Case p.y

              Case Is < 0: iSector = 1

              Case Is > 0: iSector = 2

           End Select

        Case Is > 0

           Select Case p.y

              Case Is < 0: iSector = 4

              Case Is > 0: iSector = 3

           End Select

    End Select

End Function
