Subroutine CoorXY

Autore:             Leonardo Presciuttini

Data:                 28/05/2000

Scopo:

Calcola le coordinate X e Y del foro della file j nella posizione nnn del record buc.

Chiamata da: DistInMem, CoorInMem, CalcOTL

Parametri in ingresso:

iDat     0 zona esterna; 1 zona interna

j           numero della fila

nnn      posizione nella fila

Parametri in uscita:

x,y       coordinate

iCod   0: la domanda è significativa e ammette risposta

1: non ci sono fori nella file j

            2: la posizione specificata nella fila non esiste

            9: la posizione specificata non corrisponde al foro di un tubo di scambio

Listato:

Sub CoorXY(iDat As Integer, j As Integer, nnn As Integer, _

           x As Single, y As Single, iCod As Integer)

'-----------------------------------------

           Dim yj As Single, xx As Single

           Dim cod As String, i As Integer

           If j = 0 Then iCod = 3: Exit Sub

           If DaTos(iDat).ntub(j) = 0 Then

              iCod = 1: Exit Sub

           End If

           yj = DaTos(iDat).y(j)

           xx = DaTos(iDat).x(j) - DaTos(iDat).OPASSO

           If nnn > DaTos(iDat).bu.ici Then iCod = 2: Exit Sub

           For i = 1 To nnn

              cod = Mid$(DaTos(iDat).bu.bu, i, 1)

              Select Case cod

                  Case "9":  xx = -xx - DaTos(iDat).OPASSO

                  Case Else: xx = xx + DaTos(iDat).OPASSO

              End Select

           Next i

           cod = Mid$(DaTos(iDat).bu.bu, nnn, 1)

           Select Case cod

              Case "1"

                  iCod = 0: x = xx: y = yj

              Case Else: iCod = 9

           End Select

End Sub
