Subroutine diadiffe

Autore:            

Data:                 22/04/2000

Scopo:

Calcola la differenza tra il diametro interno del mantello e l’OTL.

Chiamata da:          Sub SubTraccia, Sub SuperDiadif.

Listato:

Sub diadiffe(Diadif As Single)

        Dim TOLL1 As Integer, AG As Single, TOLL2 As Integer

        If DaTos(0).JSHELL = 2 Then GoTo 24

        TOLL1 = 3: If DaTos(0).di1 > 450 Then TOLL1 = 4

        If DaTos(0).di1 > 600 Then TOLL1 = 5

        If DaTos(0).di1 > 1375 Then TOLL1 = 7

        Diadif = TOLL1 + 10: Exit Sub

24      TOLL2 = 5: AG = 10: If DaTos(0).di1 > 450 Then TOLL2 = 7

        If DaTos(0).di1 > 600 Then TOLL2 = 10

        If DaTos(0).di1 > 700 Then AG = 13

        If DaTos(0).di1 > 1225 Then AG = 16

        If DaTos(0).di1 > 1375 Then TOLL2 = 12

26      Diadif = TOLL2 + 13 + 2 * AG

End Sub
