Function Sorvolo

Autore:            

Data:                 28/06/2000

Scopo:

Verifica la condizione di non-sorvolo.

Listato:

Function Sorvolo(iActTubo1 As Integer, iActTubo2 As Integer, iCoppia As Integer) As Integer

Dim Dist As Single, iDat As Integer, iTubo As Integer

Dim Dist1 As Single, Proiez As Single

Dim P0 As RoutBase1.clsVec2

Dim p1 As RoutBase1.clsVec2

Dim Retta As RoutBase1.clsLinea2

Dim Punto As RoutBase1.clsVec2

Set P0 = New clsVec2

Set p1 = New clsVec2

Set Punto = New clsVec2

Set Retta = New clsLinea2

Set Retta.P0 = P0

Set Retta.p1 = p1

P0.x = PuntiD(iActTubo1, 1).x

P0.y = PuntiD(iActTubo1, 1).y

p1.x = PuntiD(iActTubo2, 0).x

p1.y = PuntiD(iActTubo2, 0).y

Dist = Sqr((Retta.p1.x - Retta.P0.x) ^ 2 + (Retta.p1.y - Retta.P0.y) ^ 2)

Retta.CalcolaDir

'controlla che la coppia iCoppia (coppia attuale da montare) non sorvoli buchi vuoti

Sorvolo = False

For iDat = 0 To 1

  For iTubo = 1 To DaTos(0).ktotal

    If Accoppia(iTubo, iDat) = 0 And ((iTubo <> iActTubo1 And iDat = 1) Or (iTubo <> iActTubo2 And iDat = 0)) Then

        Punto.x = PuntiD(iTubo, iDat).x

        Punto.y = PuntiD(iTubo, iDat).y

        Proiez = Retta.Proiez(Punto) '(PuntiD(iTubo, iDat).X - Retta.P0.X) * Direz.X + (PuntiD(iTubo, iDat).Y - Retta.P0.Y) * Direz.Y

        If Proiez > 0 And Proiez < Dist Then

          Dist1 = Retta.DistPunLinea(Punto)

          If Dist1 < DaTos(0).rtubo * 2 - DaTos(0).Interf Then

             Sorvolo = True: Exit Function

          End If

        End If

    End If

  Next

Next

Set P0 = Nothing

Set p1 = Nothing

Set Punto = Nothing

Set Retta = Nothing

End Function
