Subroutine DisRod

Autore:            

Data:                 22/04/2000

Scopo:

Disegna la sezione dei tondi di scorrimento.

Chiamata da:          Sub SubTraccia.

Listato:

Sub DisRod(CERCH As Integer)

        Dim j As Integer

        For j = 1 To DaTos(0).Nrod

           If DaTos(0).runn(1, j) <> 0 Or DaTos(0).runn(2, j) <> 0 Then

              If CERCH = 1 Then

                frmTraccia.Picture1.FillStyle = vbFSSolid

                frmTraccia.Picture1.FillColor = QBColor(4)

                Monitor.Routines.cerc DaTos(0).runn(1, j), DaTos(0).runn(2, j) + 1 * Sgn(DaTos(0).runn(2, j)), 0.5 * DaTos(0).runn(4, j)

                frmTraccia.Picture1.FillStyle = vbFSTransparent

              Else

                frmTraccia.Picture1.PSet (DaTos(0).runn(1, j), DaTos(0).runn(2, j))

              End If

           End If

        Next j

End Sub
