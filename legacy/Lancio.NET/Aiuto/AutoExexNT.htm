Impossibile trovare AUTOEXEC.NT

E' stato rilevato che il sistema operativo è Windows NT.

Il programma presume di trovare nella directory di sistema (normalmente C:\WINNT\SYSTEM32) il file AUTOEXEC.NT, nel quale inserire tra i cammini di ricerca quello del file BRT71FR.EXE.

Poiché tale file non è stato trovato i programmi MS-DOS non potranno funzionare.
