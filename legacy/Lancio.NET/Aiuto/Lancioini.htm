Problemi con il file LANCIO.INI

Il sistema Lancio prevede la presenza nella directory di sistema (tipicamente C:\WINDOWS\SYSTEM) di un file di inizializzazione di nome LANCIO.INI

Esso contiene informazioni sulle aree di lavoro, sulle personalizzazioni aziendali, sul tipo di funzionamento, sull'utente predefinito.

Questo errore si produce quando il file di inizializzazione è assente o è corrotto.

Soluzione del problema

Se si ha accesso ad un'altra istallazione funzionante, si può copiare nella propria directory di sistema il file di inizializzazione. Può essere necessario modificare, con un editore di testo quale NotePad, alcune delle sue impostazioni.

Se si possiede un CD di istallazione, si può trovare in esso una copia del file.

Infine, se si è eseguita l'istallazione dalla rete, si può reperire il file sul server.
