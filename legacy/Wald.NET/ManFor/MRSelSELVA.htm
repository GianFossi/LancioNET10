Subroutine SELVA

Autore

 

Revisioni

 

Scopo

E’ la routine che funge da programma principale: essa viene chiamata dal modulo eseguibile in Visual Basic (detto ‘Wald-lato Basic’, che, a sua volta, è realizzato come una DLL ActiveX) tramite una chiamata ad una DLL standard.

Argomenti

STREAM

E’ un flusso virtuale di schede dati tipo Hollerith, o, se si vuole, di stringhe alfanumeriche a lunghezza fissa di 80 caratteri. Esso viene preparato lato Visual Basic

STAMPA

Stringa alfanumerica a lunghezza fissa di 80 caratteri: percorso e nome del file ASCII sul quale Wald-lato FORTRAN scrive il risultato delle elaborazioni. Tale file sarà ulteriormente elaborato da Wald-lato Basic.

FIRMA

Stringa alfanumerica a lunghezza fissa di 80 caratteri: nome dell’azienda, da far figurare nell’intestazione dell’elaborato.

ID

Indicatore del livello di messaggistica di debugging che apparirà nell’elaborato: 0 significa nessun messaggio di debug.
