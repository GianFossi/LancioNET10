Impossibile trovare AUTOEXEC.BAT

E' stato rilevato che il sistema operativo è Windows 2000 o Windows Millennium Edition.

Il programma presume di trovare nella directory radice di C:\ il file AUTOEXEC.BAT, nel quale inserire tra i cammini di ricerca quello del file BRT71FR.EXE.

Poiché tale file non è stato trovato i programmi MS-DOS non potranno funzionare.
