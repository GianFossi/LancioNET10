Informazioni non corrette in LANCIO.INI

Il sistema Lancio prevede la presenza nella directory di sistema (tipicamente C:\WINDOWS\SYSTEM) di un file di inizializzazione di nome LANCIO.INI

Esso contiene informazioni sulle aree di lavoro, sulle personalizzazioni aziendali, sul tipo di funzionamento, sull'utente predefinito.

Questo errore si produce, di norma, quando il file di inizializzazione contiene dei riferimenti a delle directories inesistenti. Ad ogno buon conto il messaggio di errore riporta, fra l'altro, anche la descrizione dell'errore di sistema che si è prodotto.

Soluzione del problema

Aprire, con un editore di testo quale NotePad, il file LANCIO.INI posto nella propria directory di sistema (C:\WINDOWS\SYSTEM su sistemi W95 o W98), e correggere la riga che riporta il riferimento all'area di lavoro citata nel messaggio di errore .

Se si possiede un CD di istallazione, si può trovare in esso una copia del file LANCIO.INI.

Se si è eseguita l'istallazione dalla rete, si può reperire il file sul server.
