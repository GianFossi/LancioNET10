File JOB inesistente

Il nome (o numero) di commessa deve essere composto da quattro caratteri alfanumerici, ai quali corrisponde il nome di un file con estensione .JOB. Per maggiori dettagli vedi qui.

Questo errore si presenta quando si è fatto accesso al sottomenu ‘Disegno/distinta’ del menu ‘Disegnazione’ senza prima accedere al sottomenu ‘Aggiorna Commessa’, o quando si è cambiato il nome del file job rispetto a quello proposto dal programma (cioè alla stringa costituita dai primi quattro caratteri del nome del file .VIP).

Soluzione del problema

Riaccedere al sottomenu ‘Disegno/distinta’
