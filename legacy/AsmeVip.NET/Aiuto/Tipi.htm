Tipi di membrature

Le membrature previste sono le seguenti:

  • Cilindro
  • Cono
  • Conoide
  • Fondo
  • Grande Fucinato
  • Piastra Tubiera
  • Tubi di scambio
  • Dilatatore
  • Setti Partitori
  • Apertura

Ciascuna di esse dispone di una finestra specifica per l’imputazione dei dati. Alcuni dati, comuni per tutte le membrature, sono descritti di seguito.

Materiale

Cliccando sul pulsante con il cannocchiale si accede alla Libreria materiali, se la casella ‘bound to library’ è spuntata. Si può così selezionare il materiale voluto, ed eventualmente visionarne la scheda tecnica. Se si dispone delle autorizzazioni necessarie si possono anche modificare i valori della scheda tecnica; tuttavia ogni modifica sarà permanentemente registrata nella libreria materiali. Se invece la casella ‘bound to library’ non è spuntata, si accede direttamente alla scheda tecnica del materiale. I valori in essa presenti o imputati saranno registrati unicamente nel file di input del progetto attivo.
